# MathStatistics

Statistics and probability for [MathCraft](https://github.com/ACSquaredS/MathCraft), an open-source, MATLAB-inspired numerical computing environment.

> **Status:** Early stage. The repository is set up; implementation has not started.

## Role in MathCraft

MathStatistics analyzes data: it summarizes it, models its distribution, tests hypotheses and fits regressions.

## Depends on

- [MathCore](https://github.com/ACSquaredS/MathCore)
- [MathNumerical](https://github.com/ACSquaredS/MathNumerical) for linear algebra and optimization

## Planned scope

- Descriptive statistics (mean, variance, quantiles)
- Probability distributions: density, cumulative distribution, random sampling
- Hypothesis tests
- Linear and least-squares regression
- Random number generation

## Boundaries

Generic linear algebra and optimization belong in MathNumerical. Plotting belongs in [MathVisualization](https://github.com/ACSquaredS/MathVisualization).
